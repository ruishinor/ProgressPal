# ProgressPal CS50 Edition v1.2.0 - Local-First Proof

Status: release-freeze preparation
Date: 2026-06-23
Recommended tag: `v1.2.0-local-first-proof`
Current branch during preparation: `rpg/v2`

## What This Release Is

This release freezes the current app as **ProgressPal CS50 Edition v1.2 - local-first CS50 tracker proof with gamified elements**.

It replaces the older live engine proof as the working local-first CS50 tracker baseline. The app remains browser-only, local-first, offline-capable, and independent from Harvard, CS50, edX, and OpenCourseWare.

## What This Release Is Not

This is not the completed **ProgressPal RPG v2** shell.

It does not add a backend, auth, accounts, cloud sync, analytics, telemetry, AI APIs, new database model, new sync architecture, new RPG assets, or a new engine.

It also does not complete the intended character-led campaign experience. Persistent Hero HUD, collapsed panels, quest-first flow, reward feedback, asset foundation, and campaign-map redesign belong to the next RPG shell transformation branch.

## Current Capabilities

- Local CS50x progress tracking in browser storage.
- Study session logging.
- XP and achievements based on local records.
- Course map and task/resource views.
- Insights and progress summaries.
- Local backup export, import, and reset controls.
- Offline-first/static app behavior.
- Existing RPG-flavored routes and gamified surfaces over the local engine.
- Limited/manual avatar use through the existing profile surface.

## Known Limitations

- The current UI is still primarily a tracker proof with RPG-flavored elements, not a fully realized RPG shell.
- Visual assets are incomplete. The asset ledger mostly records planned assets; no broad approved RPG asset system exists.
- The character/avatar surface is limited and partially manual.
- Some RPG v2 history documents still record module-order drift from the implementation sequence; this is historical context, not a reason to keep expanding tracker panels.
- Future RPG work should begin from a clean branch after this freeze.
