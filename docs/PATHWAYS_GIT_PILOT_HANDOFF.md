## Implemented journey and curriculum direction

One module contains five real catalogue lessons:

1. Start her: hvorfor bruke Git? Ordinary saving versus a version snapshot,
   folders/repositories, local Git versus GitHub, and a truthful full roadmap.
2. Gjør klar Windows og øvingsmappen. Open Windows PowerShell, understand a
   prompt/path, check/install Git, create a collision-checked folder, and return
   after a pause. Partial setup self-report is allowed.
3. Lag og undersøk den første versjonen. Initialize main in a new empty folder,
   local synthetic identity, starter text files, Notepad, .gitignore, status,
   staging, first commit, log/show and setup failures.
4. Velg innholdet i neste commit. Two changed files, selective staging, modifying
   a staged file again, both status columns, cached/uncached diffs, a deliberate
   staging mistake, safe unstaging and a commit excluding pending content.
5. Prøv selv: et endret mål. Reverse which file belongs in the next commit,
   inspect before acting, optionally submit only a filename list, record an honest
   applied reflection and see the planned continuation.

The roadmap accounts for deeper history/diffs and coherent commits; branching,
merge/conflicts; remotes and GitHub collaboration/authentication; progressively
riskier recovery and realistic applied changes; optional tags, bisect, hooks,
submodules, Actions and tools. Only the five authored lessons are registered.
There are no fake future nodes, inflated progress counts, prerequisites in
another programme, GitHub-account requirements or new roadmap engine.

Fresh onboarding offers Git & GitHub with nothing preselected; existing learners
use Settings → Programme. RPG Campaign opens the first real lesson. Next-part
links continue through the sequence. The existing versioned bookmark and durable
answer result support resume in RPG and Classic. Unsubmitted drafts are not
promised to survive reload. Manual completion records reviewed content, not
authenticated external activity or competence.
