# Pathways

Cross-programme learning, separate from the active study programme. The app
composition route supplies the existing Git & GitHub scope explicitly. Its IDs,
content, enrolments, evidence, bookmarks and local completion records are retained.
No schema, reward policy or active-programme mutation is introduced.

Classic and RPG have stable overview, track and lesson routes. Git preparation
uses the existing catalogue sync and non-switching enrolment repositories, each
through runLocalMutation so coordination is re-synchronized between writes.
Read-only tabs can read prepared content and cannot initialize or save it.
LessonView owns assessments/bookmarks; this host owns local completion controls.
Future tracks are not offered until authored content exists.
